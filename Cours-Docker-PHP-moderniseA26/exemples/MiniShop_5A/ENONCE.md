# MiniShop 5A — Page d'accueil
**Durée indicative : 25 à 30 minutes.**

1. Ajouter `$slogan = 'Un catalogue simple, moderne et évolutif';`.
2. Afficher le nom de la boutique dans la navigation, le titre et la page.
3. Afficher le slogan dans un paragraphe `class="lead"`.
4. Créer deux cartes Bootstrap (Produits, Catégories), en HTML statique pour l'instant.
5. Échapper le nom et le slogan avec `htmlspecialchars()`.
6. Vérifier l'affichage mobile (outils développeur du navigateur).

**À retenir :** pas de tableaux, fonctions personnelles, base de données ni MVC au 5A. Ces notions viendront ensuite.
**Note :** Bootstrap est chargé par CDN : une connexion Internet est nécessaire pour son style.
