# Exercice 5A — Présentation dynamique
**Durée indicative : 15 minutes.**

1. Conserver `$nomSite` et ajouter `$slogan` et `$annee` (valeurs de votre choix).
2. Afficher le nom dans `<title>` et `<h1>`, le slogan dans `<p>` et l'année dans `<footer>`.
3. Utiliser `<?= ... ?>` et `htmlspecialchars()` pour les textes.
4. Tester un slogan contenant `<strong>` : les balises doivent être visibles comme texte.

**Réussite :** page PHP valide, contenu dynamique visible, balises saisies affichées comme texte, lien de retour fonctionnel.
